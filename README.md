# Starship

Starship is a small space shooter built with Python and Pygame. The player pilots
a spaceship, dodges enemy fire, collects power-ups, and fights bosses that appear
as the score increases.

## Installation

From the project root:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install pygame ruff
```

## Run the Game

```bash
python game/main.py
```

## Controls

| Action | Keys |
| --- | --- |
| Move the spaceship | Arrow keys or `ZQSD` |
| Shoot | `Space` |
| Restart after game over | `R` |
| Quit after game over | `Escape` |
